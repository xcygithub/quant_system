### 问题2修复（架构）：DataManager 职责分离 ✅

**问题描述**：DataManager 一个类包含太多职责（数据库初始化、日线数据读写、分钟数据读写、财务数据读写、因子数据读写、数据更新逻辑、完整性检查逻辑），违反单一职责原则。

**修复方案**：按 architecture_analysis.md 问题2的方案进行拆分重构。

**新增文件**：
- `data/cache_policy.py` - 缓存策略（数据完整性检查逻辑）
- `data/kline_manager.py` - 日线/分钟线数据管理（纯读写）
- `data/factor_manager.py` - 因子数据管理（读写）

**重构后的职责划分**：
- `DataManager`：只负责数据库连接和表初始化，委托操作给子管理器
- `KlineManager`：日线/分钟线数据纯读写
- `FactorManager`：因子数据管理（因子元数据、因子值、IC分析）
- `CachePolicy`：缓存策略（数据完整性检查）
- `FinancialDataManager`：财务数据管理（已有）
- `DataProvider`：数据获取策略（已有）

**修改文件**：
- `data/data_manager.py` - 精简为委托模式，保留向后兼容的代理方法
- `data/__init__.py` - 导出新模块

**关键改动**：
1. DataManager 不再直接操作 SQLite，而是通过 `self._kline_mgr` 和 `self._factor_mgr` 委托
2. `CachePolicy.check_data_complete()` 替代原来的 `_check_data_complete()` 方法
3. 所有原有的公开方法（`get_daily_kline`、`get_profit` 等）保持不变，确保向后兼容

**测试验证**：
```python

```

### 问题2深度修复：KlineManager.fetch_daily_kline() ✅

**问题描述**：`DataManager.get_daily_kline()` 仍然混合了数据获取、完整性检查、保存逻辑（获取→检查→在线获取→保存→返回），违反单一职责原则。

**修复方案**：将完整的获取-检查-保存流程下沉到 `KlineManager.fetch_daily_kline()`，`DataManager.get_daily_kline()` 变为纯委托方法。

**新增方法**：
- `KlineManager.fetch_daily_kline(symbol, start_date, end_date, use_cache_only=False)`：包含完整的获取-检查-保存逻辑
- `KlineManager.set_data_source(data_source)`：设置数据源
- `KlineManager.data_source` 属性：惰性创建数据源

**修改文件**：
- `data/kline_manager.py` - 添加 `fetch_daily_kline()` 方法和数据源管理
- `data/data_manager.py` - `get_daily_kline()` 简化为纯委托方法

**关键改动**：
```python
# KlineManager 内部处理完整流程
def fetch_daily_kline(self, symbol, start_date, end_date, use_cache_only=False):
    # 1. 从数据库读取
    df = self.get_daily_kline(symbol, start_date, end_date)
    # 2. 检查完整性
    if not CachePolicy.check_data_complete(df, start_date, end_date):
        # 3. 从在线数据源获取
        df_online = self.data_source.get_daily_kline(symbol, start_date, end_date)
        # 4. 保存到数据库
        self.save_daily_kline(df_online)
        df = df_online
    return df

# DataManager 变成纯委托
def get_daily_kline(self, symbol, start_date, end_date):
    return self._kline_mgr.fetch_daily_kline(symbol, start_date, end_date)
```

