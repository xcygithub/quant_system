## 完成工作

### 问题1修复：数据获取与回测解耦 ✅

**问题描述**：回测时 `get_daily_kline` 时效性检查导致请求 today 数据，网络不通时回测失败。

**修复方案**：引入 DataProvider 概念，分离数据获取策略。

**新增文件**：
- `data/data_provider.py` - DataProvider 抽象层

**修改文件**：
- `web/app.py` - 策略回测 Tab 中使用 `CacheOnlyProvider` 获取数据
- `web/factor_backtest_page.py` - 多因子回测页面使用 `CacheOnlyProvider` 获取数据
- `docs/architecture_analysis.md` - 更新问题状态为"已修复"

**核心改动**：
1. `CacheOnlyProvider.get_stock_data()` 只读 SQLite 数据库，完全不触发网络请求
2. 回测引擎获取数据时使用 `CacheOnlyProvider`，避免网络问题
3. 行情展示（自选股详情）仍使用 `dm.get_daily_kline()`，因为用户需要最新数据

**使用方式**：
```python
from quant_system.data.data_provider import CacheOnlyProvider

cache_provider = CacheOnlyProvider(dm.db_path)
df = cache_provider.get_stock_data("000001.SZ", "2024-01-01", "2024-12-31")
```

### 问题2修复：is_single_stock 未定义错误 ✅

**问题描述**：运行回测时报错 `NameError: name 'is_single_stock' is not defined`

**根因**：`web/app.py` 第 1205 行的 `with st.spinner(...)` 缩进错误，和 `else:` 对齐而不是在 `else` 代码块内部，导致变量未定义就被引用。

**修复**：修正缩进，将 `with st.spinner` 移入 `else` 块内。

**修改文件**：`web/app.py` 第 1205 行

### 问题3修复：排名格式解析错误 ✅

**问题描述**：多因子回测点击显示因子得分列时，报错 `ValueError: invalid literal for int() with base 10: '4 / 8'`

**根因**：`multi_stock_backtest.py` 第 931 行将排名存储为字符串格式 `"4 / 8"`（排名/总数），但 `factor_backtest_page.py` 第 885 行直接用 `int(rank)` 转换。

**修复**：在 `factor_backtest_page.py` 中添加字符串解析逻辑，处理 `"排名 / 总数"` 格式。

**修改文件**：`web/factor_backtest_page.py` 第 884-885 行
