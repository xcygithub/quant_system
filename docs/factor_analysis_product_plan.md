# 因子分析功能产品方案

## 一、产品定位与目标

### 1.1 产品定位
因子分析 Tab 是量化系统的核心辅助模块，为投资者提供便捷的基本面因子计算、查询与对比功能，帮助快速了解个股和组合的基本面特征，支撑多因子选股决策。

### 1.2 核心用户价值
- **效率提升**：一键计算多只股票的因子值，无需编写代码
- **决策支撑**：快速对比个股在行业中的位置，识别估值洼地
- **透明可溯**：因子计算过程可视化，结果可导出

## 二、功能模块设计

### 2.1 功能总览

| 功能模块 | 功能点 | 用户场景 |
|---------|--------|---------|
| **因子计算** | 一键计算自选股因子 | 盘后快速更新自选股的基本面数据 |
| | 一键计算所有股票因子 | 全市场扫描，批量入库 |
| **单股查询** | 展示某只股票单个因子 | 查看特定估值指标 |
| | 展示某只股票所有因子 | 全面了解个股基本面 |
| **多股对比** | 多只股票单个因子排名 | 行业对标分析 |
| | 多只股票因子对比表格 | 组合持仓分析 |

---

### 2.2 详细功能设计

#### 模块 A：因子计算

**A1. 一键计算自选股因子**

| 属性 | 说明 |
|-----|------|
| 入口 | 因子分析 Tab 顶部主按钮 |
| 前置条件 | 用户已添加自选股 |
| 操作流程 | 点击按钮 → 显示进度条 → 计算完成 → 展示摘要 |
| 计算范围 | 自选股列表中所有股票 |
| 输出结果 | 因子值写入 `factor_values` 表，展示计算统计 |

**A2. 一键计算所有股票因子**

| 属性 | 说明 |
|-----|------|
| 入口 | 因子分析 Tab 顶部主按钮（需二次确认） |
| 前置条件 | 数据库中存在股票列表 |
| 操作流程 | 确认弹窗 → 批量计算 → 进度展示 → 结果摘要 |
| 计算范围 | `all_stocks.json` 中的所有股票 |
| 输出结果 | 因子值批量写入数据库，展示执行报告 |

**风险控制**：
- 首次使用需勾选"我已知晓全量计算耗时较长"
- 限制计算频率：两次全量计算间隔不少于 24 小时
- 提供取消按钮

---

#### 模块 B：单股因子查询

**B1. 股票搜索与选择**

| 属性 | 说明 |
|-----|------|
| 输入方式 | 下拉搜索框，支持股票代码和名称模糊匹配 |
| 默认动作 | 选择后自动触发因子展示 |
| 快捷操作 | 最近查看股票（最近 5 只）|

**B2. 展示某只股票单个因子**

| 属性 | 说明 |
|-----|------|
| 入口 | 因子类别选择 + 因子名称选择 |
| 展示内容 | 因子当前值、历史走势折线图、所属行业中位数对比 |
| 辅助信息 | 因子方向说明（正值/负向）、近五年分位数 |

**B3. 展示某只股票所有因子**

| 属性 | 说明 |
|-----|------|
| 入口 | 点击"查看全部因子"按钮 |
| 展示形式 | 分类卡片 + 表格双视图 |
| 卡片视图 | 五大因子类别分别用卡片展示，卡片内显示 2-3 个核心因子 |
| 表格视图 | 全量因子列表，支持排序 |

**表格字段**：

| 字段 | 说明 |
|-----|------|
| 因子名称 | 因子中文名称 |
| 因子值 | 当前数值 |
| 因子方向 | 正向/负向 |
| 行业排名 | 在所属行业的位置 |
| 最新财务期 | 对应财务报表的截止日期 |
| 操作 | 查看历史走势 |

---

#### 模块 C：多股因子对比

**C1. 多只股票单个因子排名**

| 属性 | 说明 |
|-----|------|
| 股票选择 | 自选股复选框 或 手动输入股票列表 |
| 因子选择 | 单个因子下拉选择 |
| 展示形式 | 水平条形图 + 排名表格 |
| 排序规则 | 可切换升序/降序 |

**C2. 多只股票多因子对比**

| 属性 | 说明 |
|-----|------|
| 适用场景 | 持仓组合分析、自选股筛选 |
| 股票范围 | 勾选的自选股 |
| 因子范围 | 可多选（最多 10 个因子）|
| 展示形式 | 热力图 + 对比矩阵表格 |

## 五、技术实现方案

### 5.1 核心模块设计

| 模块 | 职责 | 文件位置 |
|-----|------|---------|
| `FactorCalculator` | 因子计算引擎 | `strategy/fundamental_factors.py` |
| `FactorPresenter` | 因子展示与格式化 | `web/factor_presenter.py` |
| `FactorCache` | 因子数据缓存管理 | `data/factor_cache.py` |

### 5.2 数据库表扩展

```sql
-- 因子值缓存表（已在 design_phase2_fundamental_factors.md 定义）
CREATE TABLE factor_values (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    symbol TEXT NOT NULL,
    trade_date TEXT NOT NULL,
    factor_name TEXT NOT NULL,
    factor_value REAL,
    update_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(symbol, trade_date, factor_name)
);

-- 因子元数据表（已在 design_phase2_fundamental_factors.md 定义）
CREATE TABLE factor_metadata (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    factor_name TEXT NOT NULL UNIQUE,
    factor_category TEXT,
    factor_direction TEXT,
    description TEXT,
    formula TEXT
);

-- [新增] 因子计算任务日志表
CREATE TABLE factor_calc_log (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    calc_type TEXT NOT NULL,        -- 'watchlist' | 'all'
    stock_count INTEGER,
    success_count INTEGER,
    fail_count INTEGER,
    calc_time INTEGER,              -- 耗时秒数
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### 5.3 缓存策略

| 数据类型 | 缓存策略 | 失效条件 |
|---------|---------|---------|
| 因子元数据 | 内存缓存 | 程序启动时加载 |
| 单股全量因子 | Redis 1小时 | 主动刷新或新财报发布 |
| 因子排名 | 实时计算 | 用户刷新 |
| 因子历史走势 | 文件缓存 | 每日收盘后更新 |

## 六、数据展示规范

### 6.1 数值格式化

| 因子类型 | 格式 | 示例 |
|---------|------|------|
| 估值类 (PE/PB/PS/PCF) | 保留2位小数 | PE: 45.23 |
| 比率类 (ROE/ROA/毛利率) | 百分比，保留2位 | ROE: 28.56% |
| 成长类 (增长率) | 百分比，保留2位 | 营收增长: +15.32% |
| 金额类 (现金流) | 万/亿单位 | 经营现金流: 128.5亿 |

### 6.2 颜色语义

| 含义 | 颜色 | 使用场景 |
|-----|------|---------|
| 高于行业中位数 | 红色 | 估值低/盈利高/成长高 |
| 低于行业中位数 | 绿色 | 估值高/盈利低/成长低 |
| 行业平均 | 灰色 | 对比基准 |
